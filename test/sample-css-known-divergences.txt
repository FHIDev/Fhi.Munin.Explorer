# Divergences between the sample stand-in stylesheet and Fhi.Helsedata.Stiler that are KNOWN to
# stand today. `scripts/assert-sample-css-matches-stiler.sh` reads this file and fails a pull
# request that introduces a divergence not listed here.
#
# NOTHING WRITES THIS FILE. Every line is a hand edit, and that is the whole design. A guard that
# records its own failures records them instead of reporting them, and the count then only ever
# goes up. Two rules keep it honest, and both are enforced by the script:
#
#   - a divergence not listed here fails the build;
#   - a line here that no longer describes a divergence ALSO fails the build, with an instruction
#     to delete it. A list nobody prunes is a claim nobody has checked.
#
# So the count can only go down, and every step down is a decision somebody made.
#
# FORMAT, one per line:
#
#   <kind>|<at-rule context>|<selector>|<property>
#
#   missing-selector      Stiler has a rule for this selector under the munin-explorer prefix and
#                         the sample has none at all. The property field is empty. Prefix only:
#                         a BORROWED selector the sample never writes is not reported, because the
#                         sample stands in for what the component touches and no further.
#   missing-declaration   Both have the rule; Stiler declares this property and the sample does not.
#   different-value       Both declare the property, with values that differ after normalisation
#                         (rem to px, var() resolved, hex to rgb — see the engine).
#   invented-declaration  The sample declares a property under a selector where Stiler does not.
#                         A stand-in that draws something the real stylesheet does not is as
#                         misleading as one that draws nothing.
#
# The context field is the normalised at-rule the rule sits inside, empty at the top level.
#
# WHERE THIS LIST CAME FROM. 178 divergences, measured 2026-09-07 against Fhi.Helsedata.Stiler
# 0.1.38 — the version samples/HostileHost/HostileHost.csproj pins, which is the version a host
# restores. The manual diff filed under Fhi.Metadata-3dwar counted "around forty", and the two
# numbers agree: that one counted RULES and named divergences a sentence at a time
# ("`.munin-explorer-dataitem-main__column` is missing seven declarations"), where this counts each
# declaration on its own line so it has something a script can reconcile. The 62 missing selectors
# were close to the rule-level count on their own.
#
# It is 175 now, and the three that went are worth recording because they are the first proof the
# stale half of the guard works. #204 landed Fhi.Metadata-cuo0e and -7e7de while this branch was
# open — the base `.munin-explorer` rule, the drilldown's grid-column, and the sibling rule beside
# it. The guard went red on the merge with an instruction to delete three lines that no longer
# described anything, and deleting them by hand is the whole ritual: the list shrank because
# somebody fixed the stylesheet, not because a script quietly rewrote its own homework.
#
# Everything the manual diff named is in here, which is the check that the comparison is not
# missing cases: the whole `@media (max-width:1280px)` row-collapse block, the eleven
# `munin-explorer-meta` table rules, the filters toolbar and its `position: sticky`, `__column`'s
# seven declarations, `__tab-content`'s three, the expand icon's invented rotate,
# `.munin-explorer-detail`'s invented border-top, and `.munin-explorer-frequency__track` painting
# grey20 where Stiler's own comment says not to. The base rule and the drilldown's grid-column were
# in it too, until #204.
#
# IT IS 213 SINCE Fhi.Metadata-l9l2n.105, and the 39 that arrived are a new FAMILY rather than new
# drift: until that bead the comparison looked only at the munin-explorer prefix, so every rule the
# sample writes for a name it BORROWS from Stiler - the choicepicker, the buttons, the searchbox,
# `screenreader-only` - was compared against nothing at all. The sample had invented
# `white-space: nowrap` on `.dropdown-choicepicker__item`, where Stiler declares no `white-space`,
# and the 55px overhang that produced was measured against ModernHost and filed as a P2 functional
# defect in the component (Fhi.Metadata-abmom). They are listed at the bottom of this file under
# their own heading, which also says how they were measured - not against the pin, because the box
# they were found on could not restore it.
#
# IT WAS 174 SINCE Fhi.Metadata-f6az7. Three went and two arrived, and the two are the first
# entries here with an expiry condition written into them. The three that went - the choicepicker
# selector, the trigger's icon rule and the dropdown - were missing-selector lines the column
# picker's own rules made false, so the sample moved TOWARDS Stiler and the stale half of the guard
# said so. The two that arrived are the opposite case and the reason the format needed a note at

# invented against the 0.1.42 both this fixture and helsedata.no restore. They delete themselves
# the day the pin moves, and Fhi.Metadata-kpmt3 is what carries that.
#
# WHAT THIS LIST DOES NOT COVER, so a short list is never read as a close match: source order and
# specificity are not compared, so two rules that both exist and both declare the same property can
# still draw differently — Fhi.Metadata-cuo0e is that shape. Shorthands are compared as written and
# not expanded, so `padding: 8px 0` does not answer for `padding-left: 8px`; a line below may
# therefore describe two spellings of one value rather than a real difference. font-family, the
# `font` shorthand and `src` are not compared at all, because Stiler ships a typeface this

#
