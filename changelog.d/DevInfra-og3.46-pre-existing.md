- **A finding in unchanged code is Pre-existing** - The pre-PR reviewer tags a finding Important, Nit or Pre-existing, and `REVIEW.md` defines the three. A Pre-existing finding, in code the pull request does not change, starts no new review round and is not fixed in the pull request; one that would be Important always becomes a follow-up bead, and the pull request lists each. A later round does not repeat an earlier round's findings. The same rule is in DevInfra's `REVIEW.md` and team rules. (DevInfra-og3.46)
