category: Added
- **A row in a saved variable list opens into the variable's panel.** Pressing the variable's name shows its description, data period, kilde and variabelgruppe, then the same Data and Om variabelen tabs as the search panel, kodeverk and statistics included. One row is open at a time. No new class names: the panel wears the search panel's `munin-explorer-meta munin-explorer-detail`.
- **An opened list row can share its variable.** "Kopier lenke" puts a link to the variable on the clipboard and "Send via e-post" opens a message carrying it. The link searches for the variable's code within its kilde and selects it. Where the browser refuses the clipboard, as Safari can, the link is shown in a read-only field to copy by hand. `VariableExplorer` supplies the address; a host mounting `VariableListView` on its own passes the new `VariableHref` parameter, and without it the panel offers no sharing.
