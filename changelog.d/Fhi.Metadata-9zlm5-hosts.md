category: Notes for hosts
- **`munin-explorer-kilde__description` is no longer emitted by any component.** A host with a rule for it can drop that rule: it now matches nothing, on the kildeutforsker's pages and inside the variabelutforsker's drill-in panel alike. Both sample stylesheets have had it removed from their prose rule. The description is drawn as a field of the section the catalogue places it in, which wears `munin-explorer-page__fields` and is already styled; where nothing places it, it is a plain `<p>` at the top of the first section, marked `lang="no"` for an English reader, which needs no rule of its own.
