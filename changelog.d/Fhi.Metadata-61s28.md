- **A catalogue value holding several `;`-separated addresses now renders one link per address** - Gjeldende lovgivning (`applicableLegislation`) stores its laws as one string such as `http://data.europa.eu/eli/reg/2025/327/oj;https://lovdata.no/eli/lov/2001-05-18-24;…`. It now renders as a `<ul>` with one link per address, in the stored order, on every surface that draws catalogue properties: the kilde, datasamling, variable and instrument pages. A value is split only when every part is an absolute http(s) address, so a `;` inside one address's query keeps it whole, and a value with any part that is not an address stays plain text. A value typed `Url` or used as a legal-basis fact is never linked whole as one address that exists nowhere. A single address followed by a stray `;` links without it. The list carries no class name, so it gets the host's own list styling. (Fhi.Metadata-61s28)
