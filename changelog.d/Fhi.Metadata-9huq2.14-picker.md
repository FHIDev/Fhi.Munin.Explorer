category: Changed
- **The code picker under «Ønskede data» is a tree, and the tree is the only place to choose.** A parent's own box now means the code with everything under it, stored as one choice; it shows ticked, half-ticked when some codes under it are chosen (from the API's `foreldre`, so without opening the branch), or empty, with «k av n» beside it. Ticking a half-ticked parent makes it one choice; unticking one code under a ticked parent keeps its siblings chosen. ICD-10's chapters and blocks are levels of the tree, so the «Fra/Til» range field is gone: a saved range that equals a block shows as that block ticked, and one that does not stays chosen as «eldre valg» with its own «Fjern». Each opened level shows whole, with no «Vis flere»; a list of more than 200 codes opens with the search field first, which searches as you type, shows at most 100 hits and offers «Velg treffene» and «Fjern treffene». The tree follows the WAI-ARIA tree pattern (arrow keys, Space to tick, Home and End). Under it a read-only summary names what is chosen, each code a button that opens the tree to it, with «Valgt: N koder» counted by the API as the union of the choices. «utgått» comes from the API's own flag. Needs the Munin API of FHIDev/Munin #7134 (`antallKoder`, `antall`, `foreldre`, `gruppe`, `utgatt` and `codes/count-union`). (Fhi.Metadata-9huq2.14)
