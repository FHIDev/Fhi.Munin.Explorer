category: Changed
- **The code picker under «Ønskede data» is a tree, and the tree is the only place to choose.** A parent's own box now means the code with everything under it, stored as one choice; it shows ticked, half-ticked when some codes under it are chosen (from the API's `foreldre`, so without opening the branch), or empty, with «k av n» beside it. Ticking a half-ticked parent makes it one choice; unticking one code under a ticked parent keeps its siblings chosen, and is refused with a message, changing nothing, when a level on the way is cut at 200 codes, cannot be read, or the choices would pass 200. ICD-10's chapters and blocks are levels of the tree, so the «Fra/Til» range field is gone: a saved range from a block's first code to its last (E10–E14) shows as that block ticked, and saving stores the block in place of the range, only when the API counts as many codes in the block as in the range, since the range stops at its last code and leaves that code's subcodes out; any other range, and one that cannot be counted, stays chosen as it was saved, as «eldre valg» with its own «Fjern», and half-ticks the parents of its first code. The read-only summary shows a saved range as the range that is stored. Each opened level shows up to 200 codes, with no «Vis flere»; a longer level shows its first 200 and says «Søk for å finne resten»; a list of more than 200 codes opens with the search field first, which searches as you type, shows at most 100 hits and offers «Velg treffene» and «Fjern treffene». The tree follows the WAI-ARIA tree pattern (arrow keys, Space to tick, Home and End). Under it a read-only summary names what is chosen, each code in a list the picker shows a button that opens the tree to it, and a choice the tree cannot show (its code has left the list, or its list has no tab here) with its own «Fjern», with «Valgt: N koder» counted by the API as the union of the choices. «utgått» comes from the API's own flag. Needs the Munin API of FHIDev/Munin #7134 (`antallKoder`, `antall`, `foreldre`, `gruppe`, `utgatt` and `codes/count-union`). (Fhi.Metadata-9huq2.14)
