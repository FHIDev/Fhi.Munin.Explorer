category: Notes for hosts
- **`munin-explorer-list-import` and `munin-explorer-list-import__entry` are new: the notice above an imported list's table, and one row in it.** No Stiler release styles them yet; the rules are tracked as Fhi.Metadata-9huq2.41. Undrawn, the notice is unboxed text between the alert region and the table, and each entry a bullet: a row not found has its «Fjern» button under its words, an item left without its note or desired data has none, and either still reads. A host that wants the samples' look gives the notice a box, `overflow-wrap: anywhere` so a long code or a pasted URL in a note wraps inside 320px, and its lists `list-style: none`, and an entry a wrapping flex row with the button at the end, as the samples do.
