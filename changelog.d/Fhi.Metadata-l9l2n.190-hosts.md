category: Notes for hosts
- **`munin-explorer-list-status` is new: the «Historisk» mark in a list row's header, after the code.** No Stiler release styles it yet; the rule is tracked as Fhi.Metadata-l9l2n.191. Until a Stiler with it is pinned, the mark is plain text at the row header's size and weight, on its own line under a code Stiler draws as a block, or after the name, a space between, in a row with no code. A host that wants the badge styles the class itself, as the samples do (`.munin-explorer-list-status`, drawn like `.munin-explorer-versions__badge`).
