category: Notes for hosts
- **1.0 is a stability promise: from here on, anything a host has to act on is a new major version.** The contract is the components and parameters the README documents under "What a host mounts", the class names it lists under the `munin-explorer-` prefix, and the fixed section ids the detail pages name themselves, which 0.1.0-alpha.15 moved under that prefix. A catalogue-placed section's id follows the group keys in Munin's catalogue, so it is not part of the promise. A `1.0.x` release is fixes only. Adding a parameter or a name is `1.x.0`. Removing, renaming or retyping one is `2.0.0`, and so is raising the Stiler floor. What the component does is described release by release in the `0.1.0-alpha` sections of `CHANGELOG.md`.
- **1.0 is styled for `Fhi.Helsedata.Stiler` 0.1.142: run the latest Stiler, and 1.0 breaks below 0.1.114.** Running the latest was decided on 2026-09-30. 0.1.141 changes only Stiler's build pipeline, and 0.1.142 gives the sentence under the Kodeverk heading its 8px margin. 0.1.114 is the floor: the oldest Stiler 1.0 still renders correctly with, not a version to target, and raising it is a major version. 0.1.133 widened Runa's search list to 1760px for every reader, signed in or not. 0.1.134 gives the kilde, datasamling and variable pages one column with a 47em reading measure, and 0.1.135 keeps that measure to the layout where the contents list stands beside the page, so a stacked page at 1024px and narrower keeps its full width. 0.1.136 to 0.1.140 wrap long names and codes in the sticky detail bar, stack the kilde page's datasamlinger and the saved variable list as labelled cards at 767px and narrower, and keep the hidden sticky toolbar's actions out of the Tab order. The cards' labels come from this release's `data-label` cells, so a host on 0.1.139 or later with an alpha of this package gets cards without labels on narrow screens. From 0.1.114 to 0.1.133 everything renders, with the detail pages' older two-column layout. Below 0.1.114 a variable row has no visible focus ring and its chevron shows no picture.
