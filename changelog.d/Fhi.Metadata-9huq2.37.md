category: Added
- **A list imported from the old helsedata says what did not come over, until the reader hides it.** `VariableListView` draws a notice above an imported saved list's table when its import left something behind: each row that matched no variable, by its codes, with the reason in plain words, the reader's note and desired data, and «Fjern» to take it out of the report; and the items that came over without their note or desired data. «Skjul» hides the notice for good. It is a region named by its heading, not an alert, so it is not read out on every visit. A list not imported asks for nothing more; an imported list's report is read once when the list is shown, unless Munin says both its not-found and its skipped counts are 0 (the skipped count comes with Fhi.Metadata-9huq2.40, and an API without it has the report read).
- **`IMuninExplorerClient` gains `GetMyListImportReportAsync`, `DismissMyListImportReportAsync` and `RemoveMyListImportEntryAsync`, with default bodies.** A host's own implementation keeps building: the read answers null, so its readers see no notice, and the two writes throw `NotSupportedException` as `ShareMyListAsync` does. `VariableList` gains `ImportedFrom`, `ImportNotFoundCount`, `ImportSkippedCount` (null from an API that does not send it, meaning unknown rather than none) and `ImportReportDismissed`; the report is `ListImportReport`.
