category: Changed
- **The code picker is off unless the host turns it on.** Without `MuninExplorer:Features:CodePicker` (see Notes for hosts), an opened list row has no «Velg fra kodelisten», and «Ønskede data» is the field 2.18.0 had: one textarea labelled «Ønskede data» / «Desired data», described by the caption «Angi hvilke kodeverdier du ønsker å søke om» / «Say which code values you want to apply for», with the length refusal «Ønskede data kan ikke overstige N tegn.» / «Desired data must be N characters or fewer.» In the list's column the textarea is named «Ønskede data» and the row's variable, with no placeholder. Codes already saved through Munin still show, read-only, in the row and in the column. Everything this changelog says about the code picker and the picker-first «Ønskede data» holds only with the feature on. (Fhi.Metadata-l9l2n.170)
