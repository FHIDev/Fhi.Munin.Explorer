category: Changed
- **A code list of more than 200 codes is no longer fetched whole or drawn as a table, against a Munin API that serves the code tree.** «Vis koder» first asks the API's `codes/children` for one code of the list's first level; when the answer's `antallKoder` (FHIDev/Munin #7134) is over 200, it says how many codes the list has instead of fetching it. A shorter list is fetched and drawn as before, and so is every list against an older API, which has no `codes/children` or sends no `antallKoder`: there the whole list is still fetched. While an opened list row's code picker shows a code list, the Data tab leaves out that list's own «Vis koder». (Fhi.Metadata-9huq2.14)
