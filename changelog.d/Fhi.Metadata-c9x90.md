- **`DatasamlingDetail` reads the two fields the datasamling endpoint had been sending unread** - `SourceSystemLastUpdated` (`sistOppdatertKildesystem`) is the day the source system last changed the datasamling, a `DateOnly?` because the API sends a bare date such as `"2026-05-11"` with no time or offset, and a `DateTimeOffset` would invent a UTC midnight that reads as the day before west of UTC. `EffectiveInclusionAndExclusionCriteria` (`effectiveInklusjonsOgEksklusjonskriterier`) is the criteria resolved up to the kilde when the datasamling has none of its own. Both are null when the API omits them. Neither is drawn by `DatasamlingView` yet: the contract carries them so a host reading `IMuninExplorerClient` directly gets them. (Fhi.Metadata-c9x90)
