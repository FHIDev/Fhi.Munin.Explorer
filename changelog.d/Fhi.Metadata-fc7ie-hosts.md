- **Five new class names on the saved-list view: `munin-explorer-list-head`, `munin-explorer-list-create`, `munin-explorer-list-create__row`, `munin-explorer-list-create__field` and `munin-explorer-list-placeholder`.** The view's `munin-explorer-page__actions` row now sits inside `munin-explorer-list-head`, after the header, instead of above it as a child of the page root. «Legg til ny liste» carries an `icon icon-plus--white` span. A host that styles none of the new names still gets a working view; the README says what each one owes.
