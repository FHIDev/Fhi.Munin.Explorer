category: Added
- **«Ønskede data» can be chosen from the variable's code lists.** An opened row in `VariableListView` has «Velg fra kodelisten» under the free-text field when the variable has a code list whose values can be fetched, and the row has an item id. The picker has one tab per code list. A list of 200 codes or fewer is ticked whole; a longer one, and every health code system (ICD-10, NCSP, ATC), is searched and browsed as a tree, where a node can be chosen with everything under it (its count shown), and a health code system also takes a range. Expired codes are marked with their year and can still be chosen; the picker stops at 200 choices. «Lagre» stores the choices with the row's free text through `SetMyListItemDesiredCodesAsync`. No new class names: the picker uses the package's existing ones. (Fhi.Metadata-emsc0.3.7)
