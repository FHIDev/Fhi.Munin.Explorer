category: Fixed
- **The browser list's share leaves focus where the reader put it, whatever they pressed meanwhile.** When the share code arrives, focus moves to it only if it is still on «Del liste», or on nothing. The browser answers that, not a count of the presses the list knew about, so a Tab, an arrow key in an open menu, a column ticked or a click in the table no longer has the code take focus from the reader.
