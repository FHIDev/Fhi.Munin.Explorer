category: Fixed
- **The browser list's share leaves focus where the reader put it, whatever they pressed meanwhile.** When the share code arrives, focus moves to it only if it is still on «Del liste», or on nothing when «Del liste» was the last thing the reader pressed or clicked. The browser answers that, not a count of the presses the list knew about, so a Tab, an arrow key in an open menu, a column ticked or a click in the table does not have the code take focus. The rule for focus on nothing is there for Safari and Firefox on macOS, where a clicked button does not keep focus; it is tested against a stand-in for those browsers, and only Chromium was driven.
