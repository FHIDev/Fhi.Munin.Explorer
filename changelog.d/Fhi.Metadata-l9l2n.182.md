category: Added
- **A variable can be linked by its code: `?variabel=V_MFR.KJONN`, the same link in every environment.** `VariableExplorer` resolves the code through Munin and opens the variable as a search for its code, with the row of its primary datasamling open. A code that names no variable opens as a search for the code. The address and «Kopier lenke» now name the open variable by its code: the code alone for its primary datasamling's row, and the code with `datasamlingId` for a row of another of its datasamlinger. A `datasamlingId` the variable does not have, such as one from another environment, opens the primary row instead and says so when the variable has more than one datasamling. `variabelId` links keep working. `ExplorerUrlState` gains `SelectedVariableCode`, and `IMuninExplorerClient` gains `GetVariableByCodeAsync`, with a default body answering null.
