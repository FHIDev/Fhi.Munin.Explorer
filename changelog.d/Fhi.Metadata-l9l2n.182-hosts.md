category: Notes for hosts
- **`VariableExplorer` now owns the query key `variabel`, and needs Munin's code route for code links.** A host whose page already means something by `?variabel=` declines it in `DeclinedKeys`; declining `variabel` or `variabelId` keeps the open variable out of the address altogether. Code links resolve through `api/explorer/variables/code/{code}`, which Munin added under Fhi.Metadata-9huq2.27 (on test now; prod with its next release). Against a Munin without it, a code link opens as a search for the code, which finds the variable first, and `variabelId` links work as before.
