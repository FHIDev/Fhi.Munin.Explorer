category: Notes for hosts
- **`VariableExplorer` now owns the query key `variabel`, and needs Munin's code route for code links.** A host whose page already means something by `?variabel=` declines it in `DeclinedKeys`; declining `variabel` or `variabelId` keeps the open variable out of the address altogether. Code links resolve through `api/explorer/variables/code/{code}`, which Munin added under Fhi.Metadata-9huq2.27. The explorer writes a code into its own links only once Munin has answered one, so against a Munin without the route, or with a client of the host's own on the contract's default body, its links keep naming the variable by id and open it as before. A code link that arrives there anyway opens as a search for the code.
