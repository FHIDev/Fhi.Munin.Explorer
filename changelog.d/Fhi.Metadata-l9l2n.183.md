- **A datasamling with no variables offers no way to the variable list.** A datasamling the API reports with a variable count of 0 reads «0 variabler» («0 variables») in the kildeutforsker's datasamling table and has no mark to hand it to the variable explorer, which would have opened an empty list. A mark the address brings back on such a row keeps its box, so it can still be undone. The cell in the mark column stays, so the columns line up. The datasamling's own page already offers no variables link at 0.
