category: Fixed
- **The variabelutforsker's dataperiode fields show dd.mm.yyyy on every machine.** «Fra og med» and «Til og med» were native date controls, which write the date in the order of the reader's browser or operating system, so an en-US machine showed mm/dd/yyyy (ADO 115843). They are now text fields that show and take `dd.mm.yyyy` in Norwegian and English alike, with the hint «dd.mm.åååå» / "dd.mm.yyyy" under the label. `d.m.yyyy`, eight bare digits and ISO `yyyy-mm-dd` are accepted too; other slash and dash forms and two-digit years are refused with a sentence that shows the format and an example. The filter still updates when the reader leaves the field, and `dataFrom`/`dataTo` in the URL stay `yyyy-MM-dd`, so existing links open as before. A calendar button beside each field opens the browser's own calendar, and the chosen day is written into the field as `dd.mm.yyyy` and checked like a typed one; the button is drawn only once the package's browser module is listening, and where a browser has no `showPicker()` it does nothing, so the field is typed into.
