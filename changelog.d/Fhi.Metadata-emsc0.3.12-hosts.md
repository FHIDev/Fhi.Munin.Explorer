category: Notes for hosts
- **`MuninExplorer:Features:AnonymousLists` is off by default; turning it on stores a list in the reader's browser.** The key is `Fhi.Munin.Explorer:anonymous-list` in local storage, through the package's existing `explorer-interop.js`, so a host that does not serve that module, or whose readers' browsers refuse storage, gets a list that lasts for the visit and a sentence saying so. Nothing is stored about the reader, and the package shows no consent text: whether the host's privacy statement needs a line about it is the host's call. The change adds no class name.
