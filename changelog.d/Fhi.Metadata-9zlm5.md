category: Changed
- **A kilde's page has no ingress under its name; the description stands in its own section.** `KildeView` no longer draws the kilde's description under the name, where it could run to several thousand characters and push the first section far down. The catalogue's Beskrivelse field is drawn in the section the catalogue places it in — «Om kilden» (formerly «Om registeret»), where Munin places it for every kilde — and its multilingual mirror is still left out while the description is drawn. A kilde whose catalogue places Beskrivelse in no section gets its description as the first paragraph of the page's first section instead, so it is never lost and never drawn twice. The Formål field is still left out when it repeats the description word for word. The variabelutforsker's kilde panel is the same view and changes with it.
