category: Notes for hosts
- **With `MuninExplorer:Features:CodePicker` on, the browser list's carry-over writes a second local-storage key, `Fhi.Munin.Explorer:anonymous-list-claim`.** It holds a random token and an expiry time while a signed-in reader's «Lagre i Mine variabellister» runs, is removed when the press ends and lapses after 90 seconds; nothing in it is about the reader. Where storage refuses it, the press goes on without a claim, as before. The change adds no class name.
