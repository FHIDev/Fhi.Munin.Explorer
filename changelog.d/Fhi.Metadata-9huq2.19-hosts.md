category: Notes for hosts
- **Two class names are no longer emitted, so Fhi.Helsedata.Stiler's rules for `.munin-explorer-lead` and `.munin-explorer-kodeverk__reference` can be removed.** The kodeverk lead sentence is gone, and each code list's reference is now in its heading. The heading keeps its place and its classes (`.headline.munin-explorer-group`, directly before a `ul.munin-explorer-kodeverk`), so `.headline.munin-explorer-group` and `[role=tabpanel] > .munin-explorer-group:first-child` apply as before; the change is that every link now has its own heading and a `ul` of one `li.munin-explorer-kodeverk__item`, so the item's bottom border (`:last-child`) no longer separates two links of one kind — the heading's own margin does. (Fhi.Metadata-9huq2.19)
- **The code picker's tree scrolls in its own box.** A long list (Bokommune, ABR, any list of 200 codes) no longer pushes «Lagre» and «Avbryt» far below: `.munin-explorer-codetree` (the tree, not its `__group` levels) gets `max-height: 60vh`, `overflow-y: auto`, `overscroll-behavior: contain` and 2px padding so a focus ring is not cut. A focused code scrolls itself into view. The samples' `host.css` has the rule; Stiler's comes with Fhi.Metadata-9huq2.16. (Fhi.Metadata-9huq2.19)
