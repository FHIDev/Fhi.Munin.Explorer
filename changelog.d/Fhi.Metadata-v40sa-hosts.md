category: Notes for hosts
- **The contents nav has a second heading, and a new name, `munin-explorer-page__toc-toggle`.** After the nav's plain `<h2>` comes `<h2 class="munin-explorer-page__toc-toggle"><button type="button" aria-expanded aria-controls>Innhold (N)</button></h2>`, the WAI-ARIA disclosure, and the list now has an `id`. The button starts folded and is toggled by the component. A matching Stiler rule shows only the plain heading from 768px, and below it only the button, hiding the list while the button says `aria-expanded="false"`. Until a host has the Stiler release carrying that rule, both headings show and the list stays open at every width.
