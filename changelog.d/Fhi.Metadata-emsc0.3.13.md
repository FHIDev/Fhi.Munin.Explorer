- **A row of a signed-out reader's browser list can be removed from the list itself.** Each row of the list kept in
  the browser (behind `MuninExplorer:Features:CodePicker`) has a «Fjern» button in a «Valg» column, named with its
  variable as a signed-in list's is. The row leaves the browser's storage, the removal is announced, and focus goes
  to the row now in its place, else the row before it, else the list's heading when the list is empty.
