category: Notes for hosts
- **The new-window icon is your stylesheet's.** The package draws no icon; helsedata's Stiler marks every `a[target="_blank"]` with its own, and the samples now carry that rule. A host without such a rule shows the link with no visible mark, and the hidden text still reaches a screen reader through `screenreader-only`, the class the package already uses. "Another host" is compared with the page's own address as the server sees it: behind a proxy that does not forward the public host, every absolute catalogue link counts as another site. A host that renders `DetailPage` itself, outside the explorers and views, gets the Norwegian note.
