- **Search result rows that share a name show each variable's code under the name.** When two or more rows on a page
  have the same name and different codes, as a registry's numbered procedure slots do, each of them draws its code
  under the name in
  `munin-explorer-list-code`, the class a saved list already uses for its codes, and the row's name button and save
  buttons include the code in their accessible names. Rows with a unique name are unchanged, and so are the rows of
  one variable delivered from several datasamlinger, which share their code as well. No code is drawn under the name
  while the Kode column is on. No new class name.
