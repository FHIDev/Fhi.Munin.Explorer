- **A search row's code under a shared name wraps from Fhi.Helsedata.Stiler 0.1.208.** The code sits in `munin-explorer-list-code` inside the row's `munin-explorer-dataitem-main__name`, and Stiler 0.1.208 adds `.munin-explorer-dataitem-main__name .munin-explorer-list-code { white-space: normal; overflow-wrap: anywhere; }`. On an older Stiler the class keeps a saved list's `white-space: nowrap`, so a long code stays on one line past the name column: cut off at a phone card's edge and, on desktop, over the next column. A host without Stiler that styles `munin-explorer-list-code` needs the same two declarations there. (Fhi.Metadata-l9l2n.161)
