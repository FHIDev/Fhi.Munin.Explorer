- **Back from the variable explorer reopens the kilde row the reader left and returns to where they were on the page.** An open row in the kildeutforsker is now part of the address, as `?expanded=<kilde id>` repeated per open row, so a shared link opens the same rows in Norwegian and English and Back from "Vis alle variabler i …" shows that row open with its link again, instead of a collapsed list near the top. Opening or closing a row replaces the history entry rather than adding one. Where the package's browser module is served, the page scrolls back to the position it was left at, kept per tab in `sessionStorage`, or brings the first open row into view on a link opened fresh. `KildeSearch` gains `ExpandedKildeIds` and `ExpandedKildeIdsChanged` for a host composing it itself.
