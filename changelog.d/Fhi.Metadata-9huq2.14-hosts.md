- **The code picker's tree needs rules in Fhi.Helsedata.Stiler for eight new class names.** `munin-explorer-codetree` (the tree, a `ul`) and `munin-explorer-codetree__group` (each level under a code, a nested `ul`) need their list style and padding reset, with a fixed indent per level on `__group`; `munin-explorer-codetree__row` is one code's line, a grid whose first column is `munin-explorer-codetree__toggle` (the ▸/▾ arrow, blank for a code with nothing under it) and whose second is `munin-explorer-codetree__box` (☐, ☑ or ▣ for half-ticked), so boxes and codes line up by level; `munin-explorer-codetree__code` is the code in a fixed-width column, `munin-explorer-codetree__name` the name to cut with an ellipsis (the whole name is in the markup and its `title`), and `munin-explorer-codetree__count` the «k av n» beside a parent. Unstyled, the tree still works and reads correctly, with the browser's own list indent and bullets; the state is carried by `aria-checked` and `aria-expanded` on each `[role=treeitem]`, which a stylesheet may also select on. The samples' `host.css` shows one way to draw it. (Fhi.Metadata-9huq2.14)
