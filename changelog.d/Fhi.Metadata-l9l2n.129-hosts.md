- **A new name, `munin-explorer-page__fact-line`, and the «Tilgangsnivå» filter reads a new property.** A hero fact with several values — the kilde's access levels — draws each in a `<div class="munin-explorer-page__fact-line">`, one per line without any rule; Stiler adds 6px between them. The Kildeutforsker's «Tilgangsnivå» filter now reads Munin's `TilgangsnivaaHelsedata` (helsedata.no's four levels) instead of the EU `accessRights` token, which is still shown among the kilde's metadata fields; a saved link carrying an old `eu-access:` value under `tilgangsniva` matches no kilde.
