category: Changed
- **Kildeutforsker filters on helsedata.no's access levels, and a kilde's page shows them.** The «Tilgangsnivå» filter now lists helsedata.no's four levels — Statistikkbank, Tilgang krever søknad, Åpne data/statistikk tilgjengelig and Søknad via helsedata.no — in that order, instead of the EU access-rights value, and a kilde matches when it has any of the ticked ones; a saved link with an old EU value finds no kilde. The kilde page's fact row ends in «Tilgang» / «Access» with the kilde's levels one per line in the reader's language; a kilde with none has no such cell.
