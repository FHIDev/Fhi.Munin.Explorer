category: Notes for hosts
- **`VariableListView` takes an optional `VariableHref`.** A `Func<VariableListItem, string?>` returning an absolute address that opens one variable, or null where none can. `VariableExplorer` passes its own, which searches the variable's code within its kilde, so a host using it needs no change. A host that declines the `variabelId` or `search` query key gets no share controls in the list panel, nor does a variable without a code.
- **Run `Fhi.Helsedata.Stiler` 0.1.146 or later for an opened saved-list row.** On 0.1.144 and earlier the panel is squeezed into one column of the phone card, is as wide as the whole table on larger screens, and the row's chevron stands above the name instead of beside it. On 0.1.145 a code table opened inside the row loses its header row on phones and takes the list's cell padding elsewhere.
