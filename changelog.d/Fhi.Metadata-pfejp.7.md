category: Added
- **The Explorer shows Munin's English names and descriptions on English pages.** With `Language` set to English, the kilde, delkilde, datasamling, variabelgruppe and variable names and descriptions the components draw — the kilde list, the detail views, the variable rows and their panels, the filter tree and its chips, the trails and the hierarchy — is shown in English where Munin sent English for that field, and in Norwegian, marked `lang="no"`, where it did not. Each field falls back on its own, so an English name can stand over a Norwegian description. Norwegian pages are unchanged. Sorting and search still read the Norwegian names. The saved-list rows and the descriptions in a variable's version history stay Norwegian, because the API sends no English for them yet. Hosts change nothing.
- **The contracts carry the English names Munin now sends for variable rows, facets and the hierarchy's groups.** `VariableSummary.PreferredTermEn`, `KildeNameEn`, `DatasamlingNameEn` and `VariabelgruppeNameEn`; `NameEn` on `KildeFacet`, `DelkildeFacet`, `DatasamlingFacet`, `VariabelgruppeFacet`, `FilterFacet` and `HierarchyVariabelgruppe`. Each is null when Munin has no English.
