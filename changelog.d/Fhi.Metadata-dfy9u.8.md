category: Added
- **«Lagre disse variablene» saves a whole search result into the reader's list.** A signed-in reader gets the button under the result count. It saves every variable the search and filters match, on every page, into the active list (or a new «Min variabelliste» when they have none). A result of 200 or more asks first. A result above 2000 is refused with a request to narrow it. Afterwards the button reads «✓ Lagret» until the search changes, and a status line says how many variables the list did not already hold. It calls the new `IMuninExplorerClient.GetVariableIdsAsync`, which needs a Munin API with `GET api/explorer/variables/ids`. A host that implements the interface itself gets a default that throws `NotSupportedException`, and the button then reports a failed save.
- **A signed-in reader's collapsed result row has «Lagre i liste» again, for a pointer.** The button sits last in the row under the header «Valg» («Actions»). It is `tabindex="-1"`, so a row is still one Tab stop and the keyboard saves from the open panel as before.
