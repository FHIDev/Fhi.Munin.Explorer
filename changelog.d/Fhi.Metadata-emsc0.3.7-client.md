category: Added
- **The code picker's calls on `IMuninExplorerClient`.** `SearchKodeverkCodesAsync` and `GetKodeverkCodeChildrenAsync` page through a variable's code list (search, and the tree level by level, with `KodeverkCodeHit.HasChildren`); `CountKodeverkCodesAsync` counts what one `DesiredCodeChoice` covers (a code, a node with everything under it, or a range); `SetMyListItemDesiredCodesAsync` stores the item's free text with its chosen codes, answering `Refused` with `InvalidIndex` or `MaxSelections`, or the new `ListUnavailable` when the code list cannot be read to check them; `DesiredDataResult` gains `MaxSelections` and `InvalidIndex`, and keeps its three-field constructor and deconstruction. Clearing the text with the existing writes leaves the chosen codes. `ShareListAsync` now sends an item's chosen codes with it (never its free text or notes), so a share read and shared again keeps them. `VariableListItem.DesiredDataCodes` carries the chosen codes on a saved list and a shared one; in a shared list built by a client they are unchecked, so show them as text. Each new interface member has a default that refuses, so an implementation of your own still builds. (Fhi.Metadata-emsc0.3.7)
