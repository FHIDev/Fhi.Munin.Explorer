category: Added
- **A datasamling can be linked by its code, the same link in every environment.** `KildeExplorer` opens `?kilde=kreg&datasamling=<code>` as the datasamling of that kilde whose code it is, in any case and with Æ, Ø and Å folded as Munin folds codes (Æ as AE, Ø as OE, Å as AA). The kilde key may be an id or a code. A datasamling under a delkilde, at any depth, is found too. The address keeps the datasamling in the form the reader came with: a code stays a code, and `?datasamling=<id>` works and is written as before. A code that names no datasamling of the kilde shows the normal not-found view, with the code left in the address. Needs the `code` field on each datasamling of Munin's kilde detail (Fhi.Metadata-9huq2.21); against an older Munin a code link shows not found and id links work as before. (Fhi.Metadata-l9l2n.171)
