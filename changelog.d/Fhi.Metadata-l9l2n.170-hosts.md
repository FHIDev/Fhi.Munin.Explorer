- **Features a host turns on per environment live under `MuninExplorer:Features`, each off by default.** The first is `CodePicker`, the code picker under «Ønskede data». Turn it on in an environment's appsettings, with no code change, whichever `AddMuninExplorer` overload the host calls: `"MuninExplorer": { "Features": { "CodePicker": true } }` (environment variable `MuninExplorer__Features__CodePicker=true`). The delegate overload reads the key from the host's registered `IConfiguration`, and nothing else from that section, so an `ApiBaseUrl` set in the delegate is never replaced. `true` turns it on; absent or any other value is off. The key is read once, when the first component needs it, so a change takes a restart. Setting `options.Features.CodePicker` in the delegate wins over the key. A new feature a host may want on in test before production gets its own entry here, off by default, and the entry is removed once the feature is on for every host. (Fhi.Metadata-l9l2n.170)
