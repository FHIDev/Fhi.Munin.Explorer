- **«Søk om tilgang» links to helsedata.no's pages by default; a host with other pages sets its own.** The defaults are `/no/soknader/?opprettSoknad=min-oversikt`, `/no/soknadsveiledning-oversikt/personidentifiserbare-opplysninger/`, `/no/soknadsveiledning-oversikt/sok-om-anonyme-data/` and `/no/apne-data/` (Norwegian for every reader, as helsedata has no English pages for them), so helsedata needs no change. Override any one under `MuninExplorer:AccessLinks` (`ApplicationHref`, `PersonalDataGuideHref`, `AnonymousDataGuideHref`, `OpenDataHref`); an empty value drops that link. `MuninExplorerOptions.AccessLinks` and `KildeView.AccessLinks` do the same in code. A host that is not helsedata.no and has no such pages sets `MuninExplorerOptions.AccessLinks = null`, or all four keys to empty; its kilder still link to a registry's own page and to their open data. The block is the new handle `munin-explorer-kilde__access`, in an action row of its own (`.munin-explorer-page__actions`) after the name block, so a host's own `KildeView.Actions` stay where they were. Each offer is a sentence over a row of links, the main one `hd-button-square button-square--primary`. Stiler has no rule for it yet; the sample hosts set the sentences in a grid and the links in a wrapping row. (Fhi.Metadata-l9l2n.142)
