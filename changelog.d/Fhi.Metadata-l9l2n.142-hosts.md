category: Notes for hosts
- **The host supplies the pages «Søk om tilgang» links to, through configuration.** Set `MuninExplorer:AccessLinks:ApplicationHref`, `PersonalDataGuideHref`, `AnonymousDataGuideHref` and `OpenDataHref` (or `MuninExplorerOptions.AccessLinks`, or `KildeView.AccessLinks` on a direct mount). helsedata's values are `/no/soknader/?opprettSoknad=min-oversikt`, `/no/soknadsveiledning-oversikt/personidentifiserbare-opplysninger/`, `/no/soknadsveiledning-oversikt/sok-om-anonyme-data/` and `/no/apne-data/`. Without `ApplicationHref`, a «Søknad via helsedata.no» kilde gets no button. The block is the new handle `munin-explorer-kilde__access` inside `.munin-explorer-page__actions`: a sentence per offer over a row of links, the main one `hd-button-square button-square--primary`. Stiler has no rule for it yet; the sample hosts set the sentences in a grid and the links in a wrapping row. (Fhi.Metadata-l9l2n.142)
