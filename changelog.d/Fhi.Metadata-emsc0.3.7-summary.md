- **The chosen codes show as a summary in the list and the share view.** (The «Velg fra kodelisten» beside it only with the host feature `MuninExplorer:Features:CodePicker` on; the summary shows either way.) In `VariableListView`, an opened row lists the item's chosen codes above «Velg fra kodelisten», one line per code list («ICD-10: E11 med alt under (10 koder), E10–E14 (50 koder)»). A shared list gets a column «Ønskede verdier», next to the variable, when any item carries codes («Ikke oppgitt» for one without), and never shows free text. A health code system is always named by its reference (ICD-10, NCSP, ATC); any other code list by `DesiredCodeView.KodeverkName` (`kodeverkNavn`, new, when the API sends it), else by its kind. Codes and terms are text only: a share built by a client is not checked. No new class names. (Fhi.Metadata-emsc0.3.7)
