- **The chosen codes show as a summary in the list and the share view.** In `VariableListView`, a row's «Ønskede data» cell lists the item's chosen codes under its free text, one line per code list («ICD-10: E11 med alt under (10 koder), E10–E14 (50 koder)»). A shared list gets a column «Ønskede verdier» when any item carries codes, and never shows free text. The code list is named by `DesiredCodeView.KodeverkName` (`kodeverkNavn`, new, when the API sends it), else by its kind, and a health code system by its reference. Codes and terms are text only: a share built by a client is not checked. No new class names. (Fhi.Metadata-emsc0.3.7)
