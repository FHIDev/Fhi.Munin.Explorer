category: Notes for hosts
- **Run `Fhi.Helsedata.Stiler` 0.1.155 or later for the saved list's table, and know the new name `munin-explorer-list-code`.** It is the variable's code under its name; undrawn, it runs on after the name at full size, so a host stylesheet owes it `display: block`. Stiler shows the table as cards below 1280px, where six columns no longer fit, rather than below 768px. It grows the Ønskede data field, now a `textarea` where it was an `input`, to four lines with `field-sizing: content`, which Safari and Firefox do not support yet: there the field stays one line high and scrolls. A host rule written for `.munin-explorer-dataitem-main__desiredData input` no longer reaches the field.
- **`munin-explorer-dataitem-header__code`, `munin-explorer-dataitem-header__status` and `munin-explorer-dataitem-header__save` are now named in the class inventory; nothing about them changes.** The search results' header has always built them from a key, which the README's inventory could not see; a host's rules for them stand as they are.
