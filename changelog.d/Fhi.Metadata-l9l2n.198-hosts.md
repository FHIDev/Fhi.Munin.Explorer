category: Notes for hosts
- **From now on, every new feature a reader can see arrives behind a `MuninExplorer:Features` key of its own, off by default.** A host updating the package gets no new reader-visible feature until it sets that key to `true` in an environment's appsettings; fixes, changes of text, accessibility fixes and changes of styling arrive unflagged, and a follow-up to a flagged feature comes behind that feature's key. Each key is removed once helsedata has had it on in production through a release, and its feature then stays on; that removal is named here when it happens. The README's «Turning features on per environment» lists every key with the release that added it. The Munin API routes a feature calls are not flagged. `CodePicker` and `AdvancedSearch` are unchanged. (Fhi.Metadata-l9l2n.198)
