category: Notes for hosts
- **The «Søk om tilgang» links take the reader's language, and a host can set them per language.** `{language}` in an href becomes `no` or `en`, and the helsedata defaults now read `/{language}/soknader/?opprettSoknad=min-oversikt`, `/{language}/soknadsveiledning-oversikt/…` and `/{language}/apne-data/`. `MuninExplorer:AccessLinks:<no|en>:<Key>` (or `KildeAccessLinks.Languages`) overrides one language over the shared `MuninExplorer:AccessLinks:<Key>`; an empty value drops that link for that language only. The explanation moves from the action row into the «Tilgang og ansvar» section. It is drawn as `infobox infobox__datasources-block` with `illustration illustration_brand-sign`, around the existing handle `munin-explorer-kilde__access`, and its button is `hd-button-square button-square--tertiary` with `icon icon-plus--dark`, all classes helsedata's stylesheet defines. The button row (`.munin-explorer-page__actions`) now sits inside the name block, above `.munin-explorer-kilde__jumps`: one `hd-button-square button-square--primary`, and a `button-square--tertiary` «Se åpne data» beside it where the kilde has both. A kilde whose payload places no «Tilgang og ansvar» section gets the box in a section of its own after the placed ones, id `munin-explorer-access` (an id, not a class; no rule needed).
